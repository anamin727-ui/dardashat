# دردشات ♥ (Dardashat)
دردشة عربية بأربع غرف (العامة، التعارف، الألعاب، التقنية)، رسائل خاصة وحد أقصى 20 شخصاً متصلاً.
 
## نشر Render
Runtime: Docker. Environment: DARDASHAT_CLOUD=1, DARDASHAT_ADMIN_CODE=(رمز إدارة قوي وسري), DARDASHAT_DATA_DIR=/data.
 
**تنبيه هام:** خطة Render المجانية تخزن بيانات الحسابات والرسائل على قرص مؤقت **غير دائم**؛ قد تختفي بيانات مستخدمي هذه النسخة التجريبية عند الخمول أو إعادة التشغيل أو إعادة النشر. لا تستخدم هذه النسخة كموقع دردشة إنتاجي أو لتبادل معلومات حساسة. استضافة إنتاجية تحتاج قرصاً دائماً وخطة مناسبة، أو قاعدة بيانات دائمة.
لا يوجد تشفير طرف لطرف للمحادثات الخاصة.
